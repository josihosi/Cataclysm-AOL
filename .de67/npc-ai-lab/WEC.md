# NPC AI engineering toolkit

**Separate, parked contract. Only Josef can open it for delivery.** Josef wants this as the finale after the current optimization work. Finishing that work leaves this lock in place until he personally opens it.

## What Josef wants to do

Build a native NPC AI lab that makes new features faster to develop. Let a developer set up an encounter, change one thing, run it again, and see where behavior or cost first changes. A developer investigating a group that wriggles in place should be able to find the turn, watch the approach in Tiles, and inspect what each actor tried and what actually happened. The lab should be useful for building the next behavior as well as diagnosing today’s bugs.

- Author repeatable, seeded encounters with different rosters, factions, equipment, creature counts, starting positions, terrain and obstacles. Run one case by hand or many cases headless. Both modes use ordinary game turns and the same native simulation.
- Start with a local writhing stalker encounter and a well-armed faction caravan moving through a city. Exercise local decisions, entirely offscreen travel, and repeated crossings into and out of the reality bubble. Follow the same members, positions, goals and first moves across those crossings. Distant travel must work while the area stays offscreen.
- Watch either side hands-off in Tiles. Pan, follow a selected actor, pause and step without giving orders, moving the player, changing the activation boundary or affecting the simulation. Independent factions remain independent. As an optional intervention, “Play as this follower” can use the existing allied NPC debug swap in a separate playable branch. Preserve the measured baseline. Monster possession is outside this request.
- Read one whole-turn performance plot using the headless measurement. Mark overmap work and actual dispatches, local NPC and monster costs, map loads and real handoffs. Use a default adjustable 30 ms whole-turn warning including crossing turns. Support tighter scenario and overmap budgets and matched baseline differences. Show median, p95, worst turn and counts, with startup separate. Explain measured cost with work counters, inclusive and exclusive time, outstanding unattributed time and an instrumentation-off comparison.
- A warning leaves a bookmark and the batch keeps running. Click a hitch or a behavioral marker, see the preceding turns in Tiles with the same actors, inspect the relevant decisions, and follow them through the marked turn. Compare runs to identify the first divergence. Distinguish repeated ineffective attempts from useful movement, intentional waiting and tactical retreat.
- Use the World 2 dispatch investigation as the performance reference. The point is to reproduce the workload, distinguish what consumed time and see how the party subsequently behaved. The original NPC AI engineering toolkit paper informs implementation choices. The lab and these observable play paths come first.
