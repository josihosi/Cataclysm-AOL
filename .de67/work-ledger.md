# Current work ledger

## How to maintain this ledger

This is the current work queue, not project history.

- When work is completed and accepted, delete its ledger entry. Do not archive it or retain a completed checkbox. Existing acceptance records and source history remain authoritative.
- Remove the corresponding FS red lamp only when the whole requirement is satisfied; one completed task does not settle other unfinished parts.
- When no executable work remains here, inspect the FS for remaining red lamps and select the next authorized actionable outcome. Do not restart paused or withdrawn campaigns by treating them as newly discovered work.
- Keep each entry to its intended result, actual remainder, owner, concrete blocker if any, and useful existing evidence references. Replace obsolete status instead of appending a diary. Preserve independently unfinished subdivisions and ownership.
- Keep genuine pauses explicit in the FS. Withdrawn work leaves this queue. If nothing actionable remains, report whether everything is finished or which specific decision prevents progress.
